# HSC Study Tracker — GitHub Pages-এ প্রকাশ করার নিয়ম

## ১) ZIP ফাইল Extract করো
`hsc_study_tracker.zip` ফাইলটি Extract করলে `index.html`, `manifest.webmanifest`, `sw.js` এবং `icons` ফোল্ডার পাবে।

## ২) GitHub-এ Repository তৈরি
1. github.com-এ লগইন করো।
2. `+` → `New repository` চাপো।
3. Repository name দাও: `hsc-study-tracker`
4. Public নির্বাচন করে `Create repository` চাপো।

## ৩) ফাইল আপলোড
1. নতুন repository-তে `Add file` → `Upload files` চাপো।
2. ZIP Extract করা ফোল্ডারের ভেতরের সব ফাইল ও `icons` ফোল্ডার আপলোড করো। ZIP ফাইলটি নিজে আপলোড করলেই ওয়েবসাইট চালু হবে না।
3. `Commit changes` চাপো।

## ৪) GitHub Pages চালু
1. Repository-র `Settings` → `Pages` খোলো।
2. Build and deployment অংশে `Deploy from a branch` নির্বাচন করো।
3. Branch: `main`, Folder: `/(root)` নির্বাচন করে `Save` চাপো।
4. কিছুক্ষণ পর Pages-এর ওয়েব ঠিকানা দেখাবে: `https://তোমার-ইউজারনেম.github.io/hsc-study-tracker/`

## ৫) Android ফোনে অ্যাপ আইকন করা
1. Chrome-এ GitHub Pages-এর ওয়েব ঠিকানা খোলো।
2. পেজ লোড হলে Chrome-এর ⋮ মেনু চাপো।
3. `Install app` অথবা `Add to Home screen` নির্বাচন করো।
4. নাম নিশ্চিত করে Add/Install চাপো। এরপর ফোনের অ্যাপ আইকনের মতো খুলবে।

## গুরুত্বপূর্ণ
- টিক দেওয়া কাজ এই ফোনের ওই ব্রাউজারে Local Storage-এ থাকে। Browser data clear করলে বা অন্য ফোনে গেলে টিকগুলো নাও থাকতে পারে।
- রুটিনের ১৫ তারিখের C1 অধ্যায়ের লেখা ছবিতে অস্পষ্ট; প্রকাশের আগে `index.html`-এর schedule অংশে সেটি ঠিক করে নিও।
- ৫–৩০ তারিখের মাস/বছর নির্দিষ্ট করা হয়নি; অ্যাপে শুধু তারিখ নম্বর রাখা হয়েছে।
